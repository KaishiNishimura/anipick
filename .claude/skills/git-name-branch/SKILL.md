# ブランチ名生成

現在の変更内容や作業目的を分析し、適切なブランチ名の候補を提案する。
実際のブランチ作成・切り替えは実行しない。

## 手順

1. コンテキストを収集する:
   - `$ARGUMENTS` が指定されていれば、それを作業目的として扱う
   - `git status` と `git diff --stat` で未コミット変更を確認
   - `git log --oneline -5` で直近のコミット内容を確認
   - 変更がなければ `$ARGUMENTS` の内容のみから判断する

2. 既存ブランチの命名規則を確認する:
   - `git branch -a` で既存ブランチ名の一覧を取得
   - 使われているプレフィックスやスタイルを把握

3. ブランチ名を生成する:
   - 既存ブランチの命名規則に合わせる
   - 変更の種類に応じたプレフィックスを付与

## 出力フォーマット

- 推奨するブランチ名を 2〜3 案提示
- 各案にプレフィックスの選定理由を簡潔に添える
- どの案を推奨するか明示

## プレフィックスの目安

| プレフィックス | 用途 |
| --- | --- |
| `feature/` | 新機能追加 |
| `fix/` | バグ修正 |
| `refactor/` | リファクタリング |
| `chore/` | 設定・ツール・CI 等の雑務 |
| `docs/` | ドキュメントのみの変更 |
| `hotfix/` | 緊急修正 |

## 注意事項

- 絶対にブランチを作成しない（`git checkout -b` や `git switch -c` を実行しない）
- 提案のみ行う
