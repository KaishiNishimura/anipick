# コミットメッセージ生成

現在の未コミット変更を分析し、コミットメッセージの候補を提案する。
実際のコミットは実行しない。

## 手順

1. 変更状況を確認する:
   - `git status` で変更ファイル一覧を取得
   - `git diff --staged --stat` と `git diff --stat` で変更規模を把握
   - `git diff --staged` と `git diff` で変更内容の詳細を確認
   - `git log --oneline -10` で既存のコミットメッセージスタイルを確認

2. 変更内容を分析する:
   - 変更の種類を判定（新機能 / バグ修正 / リファクタリング / ドキュメント等）
   - 影響範囲を特定
   - 変更の目的を要約

3. コミットメッセージを生成する:
   - 既存コミット履歴のスタイル（接頭辞・言語・文体）に合わせる
   - 簡潔な1行案と、本文付きの詳細案を両方提示
   - 変更内容の要約テーブルも添える

## 出力フォーマット

- 変更の要約テーブル（カテゴリ / 内容）
- 推奨するコミットメッセージ候補を複数案提示
- どの案を推奨するか理由とともに明示

## 注意事項

- 絶対にコミットを実行しない
- `git add` や `git commit` を実行しない
- メッセージの提案のみ行う
